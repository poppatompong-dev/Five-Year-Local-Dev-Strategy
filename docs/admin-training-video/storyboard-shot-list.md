## Screen Recording รายละเอียด

### 1. Dashboard

- URL: `/`
- ระยะเวลาในคลิป: 10-14 วินาที
- Action:
  - เปิดหน้า dashboard
  - เลื่อนเล็กน้อยให้เห็น KPI, งบประมาณรวม, สถานะ, และแผงเร่งรัดติดตาม
  - คลิกกราฟหรือสถานะ 1 ครั้งเพื่อให้เห็นว่ากรองข้อมูลได้
- Caption แนะนำ: `เห็นภาพรวมแผน 5 ปีในหน้าเดียว`

### 2. ค้นหาและกรองโครงการ

- URL: `/projects`
- ระยะเวลาในคลิป: 18-20 วินาที
- Action:
  - คลิกช่องค้นหา
  - พิมพ์คำค้นตัวอย่าง เช่น `สวน` หรือ `ครั้งที่ 2/2568`
  - เลือกตัวกรองปีงบประมาณหรือสถานะ 1 อย่าง
  - เปิดรายละเอียดโครงการ 1 รายการให้เห็น annotation/งบประมาณ/สถานะ
- Caption แนะนำ: `ค้นหาโครงการและหมายเหตุจากไฟล์ Excel เดิม`

### 3. Export รายงาน

- URL: `/projects` หรือ `/`
- ระยะเวลาในคลิป: 12-16 วินาที
- Action:
  - ใช้ผลการกรองเดิม
  - ชี้ให้เห็นปุ่ม `Excel`
  - ชี้ให้เห็นปุ่ม `PDF` หรือ `PDF ราชการ` บน dashboard ถ้า login แล้ว
  - ไม่จำเป็นต้องโชว์ไฟล์ดาวน์โหลดจริงทั้งไฟล์ ให้ตัดตอนหลังคลิกหรือแสดง preview สั้น ๆ
- Caption แนะนำ: `ส่งออกข้อมูลพร้อมตัวกรองและแหล่งที่มา`

### 4. Admin workflow แบบเร็ว

- URL: `/login`, `/projects`, `/import`, `/admin/audit`
- ระยะเวลาในคลิป: 16-20 วินาที
- Action:
  - แสดงปุ่ม `เข้าสู่ระบบผู้ดูแล` แต่ตัดก่อนกรอกรหัสผ่าน
  - ตัดไปหลัง login แล้วให้เห็นเมนู `ผู้ดูแลระบบ`
  - แสดงปุ่มปรับสถานะ/แก้ไขโครงการ
  - เปิด `/import` ให้เห็นพื้นที่นำเข้า Excel
  - เปิด `/admin/audit` ให้เห็นประวัติการใช้งาน
- Caption แนะนำ: `ทุกการเปลี่ยนแปลงสำคัญตรวจสอบย้อนหลังได้`

## ข้อกำกับการตัดต่อ

- ใช้ zoom-in เฉพาะจุดสำคัญ เช่นช่องค้นหา ปุ่ม Export และเมนูผู้ดูแล
- ระวังไม่ให้ mouse movement เร็วเกินไป
- ถ้าคลิปเกิน 2 นาที ให้ตัดรายละเอียดหน้า import ออก เหลือแค่เห็นเมนูและหน้าจอหลัก
- หลีกเลี่ยงการโชว์ username/password หรือข้อมูลภายในที่ไม่ควรเผยแพร่
