# Recording Checklist

ใช้ตรวจความพร้อมก่อนอัดหน้าจอจริงและก่อนส่งออกคลิป

## ก่อนอัดหน้าจอ

- [ ] ใช้ browser profile ที่ไม่มี bookmark, extension bar, หรือ notification ส่วนตัว
- [ ] ตั้ง zoom browser ที่ 100% หรือ 110% ให้ข้อความอ่านชัด
- [ ] เปิดระบบที่ URL ที่ต้องการอัด และตรวจว่าโหลดข้อมูลครบ
- [ ] ปิด notification ของ Windows/Teams/Email
- [ ] ไม่แสดง `.env`, terminal, devtools, cookie, token หรือ server function URL
- [ ] หากต้องโชว์ login ให้ตัดก่อนพิมพ์รหัสผ่าน หรือ blur ช่องรหัสผ่าน
- [ ] ใช้ข้อมูลที่เผยแพร่ได้เท่านั้น หลีกเลี่ยงข้อมูลส่วนบุคคลหรือ credential จริง
- [ ] เตรียมคำค้นตัวอย่างไว้ก่อน เช่น `สวน` หรือ `ครั้งที่ 2/2568`
- [ ] เตรียมผลลัพธ์ export ไว้ล่วงหน้าถ้าจะโชว์ preview

## Shot ที่ต้องได้

- [ ] Dashboard เห็น KPI งบประมาณ สถานะ และกราฟ/แผงภาพรวม
- [ ] หน้าโครงการ เห็นช่องค้นหาและตัวกรอง
- [ ] เปิดรายละเอียดโครงการ เห็นสถานะ งบประมาณ และ annotation
- [ ] เห็นปุ่ม Excel/PDF ชัดเจน
- [ ] หลัง login เห็นเมนูผู้ดูแลระบบ
- [ ] เห็นหน้าหรือปุ่มปรับสถานะ/แก้ไขโครงการ
- [ ] เห็นหน้า `/import` สำหรับนำเข้า Excel
- [ ] เห็นหน้า `/admin/audit` สำหรับประวัติการใช้งาน

## ระหว่างอัด

- [ ] เคลื่อน mouse ช้าและชัด
- [ ] หลีกเลี่ยงการ scroll เร็ว
- [ ] เว้นจังหวะ 1 วินาทีหลังคลิกเพื่อให้ตัดต่อได้ง่าย
- [ ] ถ้าเกิด toast หรือ loading ให้รอจนอ่านออกก่อนตัด
- [ ] ไม่ต้องกดทุกปุ่มจริง ถ้าการกระทำนั้นทำให้ข้อมูล production เปลี่ยน

## ก่อนเผยแพร่

- [ ] ดูคลิปเต็ม 1 รอบโดยปิดเสียง ตรวจว่า caption ยังพอเข้าใจได้
- [ ] ดูคลิปเต็ม 1 รอบพร้อมเสียง ตรวจว่าบทพูดตรงกับภาพ
- [ ] ตรวจว่าไม่มีรหัสผ่าน username ส่วนตัว IP address token หรือข้อมูลลับ
- [ ] ตรวจว่า caption ไม่บังปุ่มสำคัญ
- [ ] ตรวจความยาวให้อยู่ในช่วง 1-2 นาที
- [ ] Export เป็น 1080p หรือ 720p ตามช่องทางเผยแพร่
- [ ] เก็บ project file ตัดต่อและไฟล์เสียงต้นฉบับไว้ใน private storage
