# บทบรรยายคลิปสั้นสำหรับเจ้าหน้าที่แอดมิน

ชื่อคลิป: **ค้นหา ออกรายงาน และจัดการข้อมูลแผนได้เร็วขึ้น**

ความยาวเป้าหมาย: ประมาณ 1:35-1:45 นาที

## Script พร้อม Timecode

| เวลา | บทบรรยาย |
|---|---|
| 0:00-0:10 | งานแผนพัฒนาท้องถิ่นมีข้อมูลจำนวนมาก ทั้งโครงการ งบประมาณ หน่วยงาน และเอกสารประกอบ การค้นจากไฟล์หลายชุดอาจใช้เวลานาน และตรวจสอบย้อนหลังได้ยาก |
| 0:10-0:24 | ระบบบริหารแผนพัฒนาท้องถิ่น 5 ปี ช่วยรวมข้อมูลสำคัญไว้ในที่เดียว เห็นภาพรวมโครงการ งบประมาณ สถานะ และความคืบหน้าตามยุทธศาสตร์ได้ทันที |
| 0:24-0:43 | เจ้าหน้าที่สามารถค้นหาและกรองข้อมูลได้ตามชื่อโครงการ หน่วยงาน ปีงบประมาณ สถานะ ยุทธศาสตร์ หรือข้อความหมายเหตุจากไฟล์ Excel เดิม ทำให้หาข้อมูลประกอบงานวิเคราะห์ได้เร็วขึ้น |
| 0:43-1:01 | เมื่อได้ชุดข้อมูลที่ต้องการแล้ว สามารถส่งออกเป็น Excel หรือเปิดรายงานรูปแบบ PDF สำหรับใช้งานราชการได้ โดยระบบแนบข้อมูลกำกับ เช่น วันที่ส่งออก แหล่งข้อมูล และตัวกรองที่ใช้ |
| 1:01-1:22 | สำหรับผู้ดูแลระบบ หลังเข้าสู่ระบบแล้วจะสามารถปรับสถานะโครงการ แก้ไขข้อมูล เพิ่มรายการ นำเข้าข้อมูลจาก Excel และดูประวัติการใช้งานได้ การเปลี่ยนแปลงสำคัญจะถูกบันทึกไว้เพื่อการตรวจสอบย้อนหลัง |
| 1:22-1:38 | จากงานเอกสารที่กระจัดกระจาย ระบบช่วยให้เจ้าหน้าที่ทำงานเป็นระบบขึ้น ลดเวลาค้นหา ลดงานซ้ำ และใช้ข้อมูลขับเคลื่อนการติดตามแผนได้มั่นใจมากขึ้น |
| 1:38-1:45 | ระบบบริหารแผนพัฒนาท้องถิ่น เทศบาลนครนครสวรรค์ คิดเป็นระบบ เขียนเป็นจริง ขับเคลื่อนเมืองด้วยข้อมูล |

## เวอร์ชันสั้นมาก ถ้าต้องการตัดเหลือประมาณ 60 วินาที

งานแผนพัฒนาท้องถิ่นมีข้อมูลจำนวนมาก ทั้งโครงการ งบประมาณ หน่วยงาน และเอกสารประกอบ ระบบนี้ช่วยรวมข้อมูลไว้ในที่เดียว ให้เจ้าหน้าที่เห็นภาพรวม ค้นหาโครงการ กรองตามปีงบประมาณ สถานะ หรือข้อความจากไฟล์ Excel เดิมได้รวดเร็ว เมื่อได้ข้อมูลที่ต้องการ สามารถส่งออกเป็น Excel หรือรายงาน PDF เพื่อใช้งานราชการได้ทันที สำหรับผู้ดูแลระบบ ยังสามารถปรับสถานะ แก้ไขข้อมูล นำเข้าไฟล์ และตรวจประวัติการใช้งานย้อนหลังได้ ช่วยลดเวลาค้นหา ลดงานซ้ำ และทำให้งานติดตามแผนเป็นระบบมากขึ้น
