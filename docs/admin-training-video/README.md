## เป้าหมายคลิป

- ความยาวเป้าหมาย: 1-2 นาที
- ภาษา: ไทย
- โทน: ราชการร่วมสมัย อบอุ่น เข้าใจง่าย
- กลุ่มผู้ชม: เจ้าหน้าที่แอดมิน/นักวิเคราะห์นโยบายและแผน ไม่จำเป็นต้องมีพื้นฐานสารสนเทศ
- แนวทางภาพ: Sora สำหรับภาพเปิด/ภาพเชื่อม + screen recording จริงสำหรับ workflow ในระบบ

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `voiceover-script.md` | บทบรรยายหลักพร้อม timecode โดยประมาณ |
| `storyboard-shot-list.md` | ลำดับภาพ, หน้าจอที่ต้องอัด, และจังหวะตัดต่อ |
| `sora-prompts.md` | prompt สำหรับสร้าง Sora shot เปิด/เชื่อม/ปิด |
| `sora-shot-*.txt` | prompt แยกไฟล์สำหรับเรียก Sora CLI ได้ทันที |
| `captions.md` | ข้อความ caption บนจอและ subtitle แบบย่อ |
| `admin-training-video.srt` | subtitle พร้อม timecode สำหรับนำเข้าโปรแกรมตัดต่อ |
| `recording-checklist.md` | checklist ก่อนอัดหน้าจอจริงและก่อน export คลิป |
| `generate-sora.ps1` | สคริปต์ PowerShell สำหรับ generate Sora ทั้ง 4 shot หลังตั้งค่า billing/API พร้อม |
| `generation-status.md` | สถานะการทดลอง generate และวิธีรันซ้ำ |

## แนวทางผลิตที่แนะนำ

1. อัดเสียงตาม `voiceover-script.md` ก่อน เพื่อให้รู้จังหวะภาพรวม
2. สร้าง Sora shot ตาม `sora-prompts.md` แบบไม่มีข้อความไทยฝังในภาพ แล้วใส่ caption ภายหลังในโปรแกรมตัดต่อ
3. อัดหน้าจอจริงตาม `storyboard-shot-list.md` โดยใช้ข้อมูล demo/ข้อมูลที่เผยแพร่ได้
4. ตัดต่อโดยสลับ Sora shot กับ screen recording จริง
5. ใส่ caption จาก `captions.md`
6. ตรวจความปลอดภัยด้วย `recording-checklist.md` ก่อนเผยแพร่

## ข้อควรระวัง

- ห้ามแสดงรหัสผ่าน, cookie, token, environment variable หรือ URL server function ภายใน
- หากต้องโชว์หน้า login ให้ตัดก่อนพิมพ์รหัสผ่าน หรือใช้ภาพ mock/blur
- Sora ไม่เหมาะกับการสร้าง UI ระบบจริงแบบตัวหนังสือตรง 100% จึงให้ใช้ screen recording จริงในช่วงสาธิตระบบ
- หลีกเลี่ยงภาพคนจริงหรือบุคคลสาธารณะใน Sora prompt ใช้ภาพเจ้าหน้าที่แบบ generic เท่านั้น
