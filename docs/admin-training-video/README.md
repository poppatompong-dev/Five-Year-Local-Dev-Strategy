## เป้าหมายสื่อ

- ภาษา: ไทย
- โทน: ราชการร่วมสมัย อบอุ่น เข้าใจง่าย
- กลุ่มผู้ชม: เจ้าหน้าที่แอดมิน/นักวิเคราะห์นโยบายและแผน ไม่จำเป็นต้องมีพื้นฐานสารสนเทศ

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `voiceover-script.md` | บทบรรยายหลักพร้อม timecode โดยประมาณ |
| `storyboard-shot-list.md` | ลำดับภาพ, หน้าจอที่ต้องอัด, และจังหวะตัดต่อ (อ้างอิงถ้าต้องการผลิตวิดีโอจริง) |
| `captions.md` | ข้อความ caption บนจอและ subtitle แบบย่อ |
| `admin-training-video.srt` | subtitle พร้อม timecode สำหรับนำเข้าโปรแกรมตัดต่อ |
| `recording-checklist.md` | checklist ก่อนอัดหน้าจอจริงและก่อน export คลิป |
| `generation-status.md` | สถานะการสร้างสื่อ |

## แนวทางถ้าต้องการผลิตวิดีโอจริงในอนาคต

1. อัดเสียงตาม `voiceover-script.md` ก่อน เพื่อให้รู้จังหวะภาพรวม
2. อัดหน้าจอจริงตาม `storyboard-shot-list.md` โดยใช้ข้อมูล demo/ข้อมูลที่เผยแพร่ได้
3. ใส่ caption จาก `captions.md`
4. ตรวจความปลอดภัยด้วย `recording-checklist.md` ก่อนเผยแพร่

## ข้อควรระวัง (ถ้าอัดหน้าจอจริง)

- ห้ามแสดงรหัสผ่าน, cookie, token, environment variable หรือ URL server function ภายใน
- หากต้องโชว์หน้า login ให้ตัดก่อนพิมพ์รหัสผ่าน หรือใช้ภาพ mock/blur
